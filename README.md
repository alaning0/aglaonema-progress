# Aglaonema restore

Progress gallery for Alan’s Chinese Evergreen coming back from wind-snapped canes.

Live site: https://alaning0.github.io/aglaonema-progress/

## Add a photo

1. Drop an optimized JPEG into `photos/`
2. Add an entry to the `photos` array in `index.html` (date, time in Pacific/Auckland as PT, label, caption)
3. Commit and push to `main` — GitHub Pages updates automatically
